# 策略沿革

本项目的自动模拟运行经历了早期盘口动量和 Ray 尾盘 TWAP 两个主要阶段。表中日期采用香港时间。

| 日期 | 已运行策略或工作流的变化 |
| --- | --- |
| 2026-09-12 | 早期策略已用实时行情自动模拟。按同一方向合约过去 30 秒的报价涨幅筛选入场，预先计入可执行的往返成本和缓冲。 |
| 2026-09-18 | 改用市场信息退出。所持方向出现反转时尝试卖出，剩余仓位进入核实结算流程。手动入场与自动入场分别统计。 |
| 2026-10-17 | 自动模拟主策略切换为 Ray。将观察集中在每轮最后 120 秒，以 60 秒 TWAP 相对开盘基准的偏离和合约报价判断入场。 |
| 2026-10-22 至 10-23 | 每轮只允许一次实际买入成交，部分成交也占用这次机会。开盘基准改用与市场身份和时间匹配的开盘 60 秒 TWAP。 |
| 2026-10-26 | v8 在收到新的盘口或 TWAP 事件时重新检查完整入场条件。自动仓位沿用 2.5% 基线。动态门槛和动态仓位保留为旁路观察方案。 |
| 2026-11-05 | 异常重启后，使用可核实的记录和账户状态恢复运行。未知尾部单列。 |
| 2026-11-07 至 11-08 | 迁移到 Windows 便携版，核对模拟账户和账本。原实例于 11 月 8 日正常停机并归档。 |

早期策略由合约本身的报价变动驱动。Ray 用比特币参考价决定候选方向，再核对合约的可交易价格。v8 保留分时段偏离门槛、报价保护和单轮一次开仓，持仓等待核实结算。[早期动量实现](../app/lab/dashboard/forward-strategy.mjs) · [Ray 实现](../app/lab/dashboard/ray-strategy.mjs)

## 研究候选

10 月 23 日还回放了两个候选。第一种放宽尾段入场价格区间，第二种再加入短时间内 TWAP 快速变化的入场分支。两者在研究中分别统计，运行沿革表只记录实际启用的策略。分时门槛和仓位的动态变体也保留在观察研究中。不同成交延迟、价格保护和有效样本会改变回放结果，比较时需使用同一套执行假设。 [研究方法](METHODOLOGY.md)
