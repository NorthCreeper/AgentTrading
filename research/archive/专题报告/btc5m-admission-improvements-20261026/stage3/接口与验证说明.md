# 概率与流动性仓位影子模块

阶段3实现日期：2026-10-26。仅新增 `probability-sizing.mjs` 和测试，不修改实际仓位模块、控制器、策略、资金或订单。

## 集成入口

```javascript
import {computeProbabilitySizingShadow} from './probability-sizing.mjs';
const diagnostic=computeProbabilitySizingShadow({
  equity, cash, book, market, now, roundUsedShares, maxShares:100
});
```

`equity`应来自当前可信净值；`cash`为实际可用现金；`book`是当前拟买方向的原盘口，必须含tokenId、双侧深度及源/接收时间；`market`是原完整盘口身份与当时tick/minSize/fee元数据。此函数无网络、文件写入或下单。

任何结果始终包含：

- `scope:'shadow-only'`、`adopted:false`、`actualAllocation:0.025`、`actualOrdersPlaced:0`、`requiresParentAdmission:true`。
- `baseline`为原computeRayAmountSize的诊断副本，含cashSufficient；原2.5%请求、部分FAK、整笔超份额拒绝等行为保持。
- `liquidityCapacityPct/MaxSpend`是按现金、价格保护、完整深度与100份限制计算的影子可执行上限，可能低于2.5%；`liquidityCapacityMeetsMinimum`明确其能否满足最低计划比例。它不是已批准的实际仓位。
- 无可信校准默认 `status:'unvalidated'`，`probabilityLowerBound/rawPct/candidatePct:null`，不会用未知概率算零风险或放大。

盘口不在当前80–85¢、时钟未知/未来/过期、市场身份或元数据缺失时仍返回未知诊断；不恢复固定美元总成本限制，也不改变其他入场条件。

## 未来可信校准接口

当前**没有安装任何校准登记**。将来只有经独立复核的本地只读登记才能提供这些可选输入：

- `calibrationJson`：原始UTF-8 JSON文本，精确SHA256绑定全部证据。
- `calibrationRegistry`：由调用方独立维护的登记列表，须含registered、scope、原文SHA、modelId/modelSHA、protocolSHA、预注册/登记时刻与允许group；不信artifact自称registered。
- `prediction`：绑定model、calibration ID/SHA、group、当前feature SHA、slug/condition/token/outcome、decision与knownAt、下界概率。
- `expectedFeaturesSha256`与`expectedGroupKey`：调用方从当前已知特征独立得出的绑定；不能照抄prediction自称的值。

校准文件须明确目标为已核实官方胜方，标明Gamma/CLOB核实、日期外验证、日期聚类95%单侧下界、至少3个唯一纽约验证日期及至少59个样本；训练、预注册、验证、knownAt、登记和有效期必须严格按时序，原文与注册模型/协议SHA一致；概率下界至少95%，与反向率上界互补。预测不得未来、不得超过5秒，不能超出该校准的概率下界或改变身份。登记检查只能验证预登记证据的绑定和结构，不能代替对真实原数据的独立统计审核。

即使以上全部合格，也只返回 `status:'candidate-ready-shadow'`；**实际配置仍2.5%，不会自动接交易**。

## 候选计划

按 `w=0.10*max(0,(p_L-c)/(1-c))` 计算十分之一Kelly，c为候选实际逐档含费均价。以美分预算在不超过模型比例、现金、完整深度和100份的范围内规划合法请求；报价仍调用原oneTapQuote，保留2¢/85¢、最低份额、五位逐档费用和金额/含费预算的区别。更深档价格抬高成本后会重新限制Kelly比例。

候选不满足2.5%最低计划比例时跳过，不强抬预算、不在签出大请求后缩份额。部分深度不足只影响影子加码候选，原baseline的FAK部分成交继续照实保留。

## 验证

13项新测试及8项原sizing回归共21项通过。其中100组不同价格梯级、现金、净值与已用份额，独立通过原PaperBroker核对实际费用、名义额与数量；另含未来/篡改/缺失校准、假特征绑定、最低请求与100份、部分成交、深度成本反馈、输入无变更等。

`sizing-diagnostics.json`包含只读实际账户观察和明确标为hypotheticalOnly的公式/深度示例，没有把假设概率伪装成真实校准。300次未校准影子诊断微基准平均约0.03ms，具体值见该文件；不构成完整工作流延迟保证。
