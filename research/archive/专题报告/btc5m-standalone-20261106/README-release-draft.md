# BTC5M 独立工作流

这是可单独解压使用的Windows x64应用，已随附Node运行程序与固定版本SDK。启动、控制台、账本和数据保存不依赖ChatGPT或Codex。行情与交易接口仍需要互联网。

## 第一次使用

1. 把整个 `BTC5M-Standalone` 文件夹解压到本机可写目录；可使用中文或带空格的路径。不要只复制其中的程序文件。
2. 双击“启动.cmd”或“Start.cmd”，等待本机控制台打开。发行默认入口为 `http://127.0.0.1:18890/`。
3. 新安装没有账户、钱包或交易历史：模拟资金为0，工作流停止，真实交易关闭。需要模拟时，先在“账户与收益”添加模拟资金，再启动工作流。
4. 所有运行数据、日志及备份都保存在应用目录。关闭浏览器不会自动退出后台；需要彻底退出时使用“停止.cmd”。

当前主策略使用最后120秒、各时段TWAP门槛、盘口价格保护与单盘口一次开仓；计划仓位采用2.5%基线，允许规则范围2.5%–10%。没有通过验证的信号强度模型时不会自行提高仓位。具体准入及阻止原因以控制台当前显示为准。

## 钱包与真实交易

“我的钱包”是公开地址和现金余额的只读查看；不会因连接而启动真实交易。

真实交易在单独模块中设置已有账户、选择签名方式并核对前置条件。可以使用支持扩展的浏览器钱包逐次确认签名，或由你自行选择本机加密凭据方式。浏览器签名需要该页面与钱包保持可用；使用本机凭据的后台自动运行不依赖浏览器页面。

每次后台重启后，真实交易都保持关闭，需要你重新解锁、核对并明确启用。真实账户与模拟账本分开；未知订单、未核实成交、费用或结算仍按未知保留，不当作零成交或盈利。停止新入场不会抹去已提交订单或持仓，状态以核对账本为准。

此发行版只做过模拟接口和故障测试，没有使用你的账户验证真实成交、授权、费用或兑付。不会替你创建钱包、转账入金或申请官方账户权限；这些操作应由你在官方渠道完成。

## 常用操作

- **启动 / Start**：启动本应用的后台并打开控制台。
- **停止 / Stop**：停止本应用后台；不会关闭其他目录或其他端口的工作流。
- **诊断 / Status**：查看本应用身份、后台与接口状态。
- **备份 / Backup**：生成带核验清单的备份；普通备份不含钱包加密凭据。
- **恢复 / Restore**：在停止状态下恢复已核验备份，保留恢复过程记录。
- **Install-Autostart / Remove-Autostart**：可选的Windows登录后托管。它依赖用户登录，不等于未登录也运行的系统服务。
- **迁移旧账户**：单独的迁移工具，需要明确指定旧目录并先核验；普通新安装不会自动读取旧工作流。

## 搬迁与更新

需要搬迁整个工作流时，先使用“停止”确认后台退出，再复制完整应用目录。资金、账本和持仓应作为一致数据整体搬迁，不能只拷一个正在写入的状态文件。也可以使用备份、恢复工具进行核验。

本ZIP不含你的旧账户、旧研究数据、钱包地址或凭据。历史资料须另行导入到应用的归档目录；缺失资料会明确显示不可读，不会冒充完整历史。

发行清单 `package-manifest.json` 记录程序、SDK与运行时哈希；`resources/release-source-manifest.json` 登记应用源码。不要手动混合不同发行版文件。修改发行配置中的端口后，所有入口应使用同一份配置；请避免和已有工作流占用同一端口。

本机加密密码和钱包恢复资料应由你自己保存。正常备份排除加密凭据，复制备份前请查看工具提示的实际范围。
