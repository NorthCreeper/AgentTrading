# Static-only root source phase

This new pure helper consumes ten exact root-native artifact pins and raw bytes of their nine small JSON artifacts. It never reads anchors, raw prefixes, labels, accounts, or fitted values and never writes files. Root must authenticate ordinary resolved native identity/length/SHA, genuine actual terminal receipts, all source current/copy closures and retained-v2 current/copies before calling it. Rehashed declarations and `digest(pins)` are not native authentication by this pure helper.

Pins: `manifest`, `report`, `anchors`, `independentProof`, `modelHold`, `sourceRunReceipt`, `independentRunReceipt`, `originalParentGuard`, `sourceRunRegistration`, `sourceStageAcceptance`. The extra parent guard is the completed `parent-source-before-after.json`; the source registration is the root registration used for the completed v3 extraction. Both bind to the independent full proof. The completed root source-stage acceptance binds seven actual artifact pins and 44 current/copy pairs, including eleven post-completion retained-v2 pairs matched against the root registration.

The source receipt is the genuinely retained tool result, `version:root-retained-tool-terminal-output-v1`, with actual tool exit/chunk/session and its later storage time. The independent receipt is the real `native-process-result.json` with `actualStatus`, start/complete and original registration/authorization/stdout/stderr hashes. Extraction timing comes from the source report; the later source receipt storage time is never used as extraction completion or an invented root dispatch clock. Independent native times cover its proof, audit starts after report completion, and static registration follows native completion and completed root-stage acceptance.

`prepareStaticSourcePhase` checks completed v3/43 original prefixes and fixed cutoff/bytes, full original-prefix identities, all release/cause proofs, real gzip CRC/ISIZE/member/decoded-byte verification, exact complete storage equality, original-seven parent before/after evidence, retained-v2 eleven declared current/copy pairs, accepted twelve-source pure solver/model hold, and extraction→audit→registration timing. Every public aggregate field independently rederived from source is compared deeply. Independent `report.emitted` is checked separately against producer slots; the producer has no `emitted` field.

Date selection uses only `calendarEndedSourceDates.filter(day => daily[day].staticAnchors > 0)`. It validates calendar end, source population, safe counts and ordering, selects the first thirteen, and partitions 7/3/3. A static date with zero USD anchors stays valid for this static-only phase. `acceptedStaticEndedDates`, `scope:'static-only'` and `USDThirteenDateQualificationGranted:false` distinguish it from the unchanged USD study. The shared split-validator version is a schema compatibility identifier; the static scope does not grant USD eligibility.

Output binds source acceptance, static date registration and cohort split. Labels, fits, cash replay, accounts and actual orders remain prohibited. Root must save and native-pin these outputs before separately registering strict original label evidence or an actual static model study. Sparse coverage is not promoted to continuous-day coverage or a profitability claim. True source-clock/unknown/malformed prefix masks remain retrospective source qualification, and recorded clocks do not certify physical UTC synchronization or executable exchange prices.

Original USD phase files and all prior source/model/profit failures remain unchanged. Synthetic tests use invented JSON bytes, identities, terminal observations and gzip placeholders; they do not certify actual artifacts. New substantial test proofs/copies reside on D: and preserve the original disk/output reserves.
