# USD路径窗口单坐标W：纯模型设计

W只替换原U第六个残差坐标，不增加指示器组合或调交易门槛。B0/T/C/U/W全部在同一新路径来源支持内重新拟合/对比，原静态预掩码轮权重保持。七坐标标准化包含原U及W，以使两者的各自训练支持都作用于共同人口；T/C/U参数不能从更广原来源直接移用。

原七训练/三验证/全部评分、300训练轮/30方向、60秒purge、25%尺度floor、ridge20/严格驻点保持。W须验证CE/Brier同时改善C和U、2/3日及全部剔除一日改善U，评分完整报告。点模型没有置信概率或bootstrap；即使通过也必须另行原始帧扣费/延迟/部分成交/有限资金及整个退出/未来确认。

本目录尚无真实目标/拟合/资金。来源完整独审结束及根验收后，须在目标读取前单独冻结真实支持日期与所有原标签文件。根登记绑定精确来源、源码、参数、模型出生时刻；合成模型或来源日期通过不当收益。
