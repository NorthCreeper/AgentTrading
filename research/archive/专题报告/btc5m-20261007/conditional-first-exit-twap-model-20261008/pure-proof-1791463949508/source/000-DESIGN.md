# First-exit K/H held-terminal model

H is the single reference coordinate registered before its actual source run. It changes no entries or first exit triggers. All previous K/E and static failures are retained. The accepted source contains 1658 first exits, 1201 reference-supported original first exits and 15 complete days; its separate independent implementation reconstructed all 4974 signal/delay classifications directly from the fixed 115 original prefixes. Dates are newly frozen before H's target/model work: first7 train, next3 validation, all5 remaining score. This retrospective cohort has been inspected in earlier research; it is not fresh prospective evidence.

Fit new same-cohort held-midpoint-offset K/H heads separately by entry origin. K uses intercept, standardized held midpoint logit and log actual remaining time. H adds exactly asinh(held signed reference opening distance/(max(training positive raw sigma p25,current raw sigma)*sqrt(source remaining time))). Raw TWAP sigma is a feature scale, not a Brownian settlement assumption. For point fit and EACH of 128 seeded seven-day draws, re-estimate the positive sigma weighted left-continuous p25 from retained training rows only, using ORIGINAL round/origin 1/N multiplied by that draw's date count; never normalize missing mass. That draw also re-estimates normalization and both heads. Each head uses its draw's floor when predicting. All point/draw coordinates must remain within |z|<=6 on shared K/H support. Constant coordinates use the previously audited exact-constant convention.

Use original ridge20, tolerance1e-8, max100, clip1e-6, >=300 unique rounds/7 dates/>=30 official Up and Down and >=30 held payout zero/one rounds. Labels require separate strict S outcome archives with original canonical market identity and observed-known time; P is only a financial/conflict reference. Since H uses opening distance, strict opening must additionally match the original source opening within the existing 1e-5 tolerance. Targets known before validation start minus60s train only; no score retraining or parameter rescue. Unknown reference/target/direction remains unknown.

Validation continuation requires overall H CE+Brier below K, at least2of3 daily CE improvements and every leave-one-validation-day-out CE improvement. Every score date and rejection remains reported even on failure. This is a probability diagnostic gate, not sufficient for profitability. Only a later separately registered finite-cash comparison may establish a tradeable improvement: fee-net sale vs lower-held terminal value, original raw first delays, partial fills, occupied unresolved cash, $100/$10 capital controls, pressure fees/latency, and all old economic/family/concentration/forward-birth requirements. No main changes or orders are performed by this package.
