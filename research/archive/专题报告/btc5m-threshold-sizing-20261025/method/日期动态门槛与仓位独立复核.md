# 日期、动态准入与仓位：独立方法复核

复核日期：2026-10-25，香港时间。范围为既有研究、当前纯函数和官方规则的只读复核，没有修改生产、策略、资金或日历资产。本文件是研究建议，不是通过验证的部署参数。

## 现有证据支持什么

2026-10-23原参数全历史回放中，38个可证明成交盘口30胜8负，胜率78.95%，按盘口等权的普通二项Wilson95%区间为63.65%–88.93%。这仍未处理同日相关性，不能作为更强的按日聚类置信结论。早间23/27的85.19%胜率区间也宽至67.52%–94.08%；日间4/7为25.05%–84.18%，夜间3/4为30.06%–95.44%。分时段点胜率不足以直接发出新美元阈值或10%加码。

旧日期研究读取40个纽约日，但所有36个日期/时段单元均未通过事前采用条件。周末35/30/40美元仅是噪声候选：早间5/3个训练/后段日期不足，日间及夜间前后噪声比变化33%和37%。NYSE整日休市只有纽约9月7日尾段6完整轮，提前休市无完整日期，独立联邦假日主要只有10月12日。不能从这些样本给出每个美国节假日的获证门槛。

当前动态影子为 `base * clamp(sqrt(RV30m/RV6h),0.5,2) * sqrt(remaining/120)`，使用当时已收到的TWAP60、两窗80%覆盖及六小时预热。它从未被认证为结算胜率；旧共同人口317轮，1秒研究下动态只成交6个独立盘口。`rayStrengthAllocation()`仍明确返回2.5%、validated=false。

## 两个目标应怎样定义

“触发时可买”与“之后少反向”有取舍。更低的阈值通常更容易在价格仍处80–85美分时触发，却也可能增加反向；极高阈值或不交易也能得到虚假的零反向。因此应同时报告：

1. 同一有证据人口中，门槛首过次数、首过时80–85美分且对侧≤20美分的可买率；
2. 首次过门槛至首次同时满足全部准入条件的等待，期间价格超过85美分的错过率；
3. 真实1秒/2秒后新鲜盘口内的可成交量、部分成交和零成交，而非同帧PaperBroker的100%；
4. 同盘口只计一次，官方相反结算率、按纽约日期聚类置信上界及实际成交数量；
5. 扣费后净额、最大损失、资金占用，不能以胜率掩盖大亏小赢。

若挑选“反向率95%上界≤10%时可买率最大”的候选，至少保留不可行（没有任何足够证据的候选）这一结果。可再展示≤5%一档的前沿，不能临时放宽指标让某个候选获选。

## 更合适的动态门槛定义

令 `A_t`为当时已知官方对齐TWAP60，`K`为准确开盘TWAP60/当时已知有效官方基准，`s`为拟买方向（Up=+1、Down=−1），`R=A_T−A_t`为最后官方TWAP与当时TWAP之差。

推荐把门槛当“到最终还可能向不利方向移动多少”的条件分位，而不是把当前偏离倍数当胜率：

`B_t = max(0, -Q_epsilon[s * R | remaining, past_volatility, past_trend, session, calendar])`

只有 `s*(A_t−K) >= B_t`，并且盘口价格、来源时钟、准确开盘、费用和全部原风险约束同刻合格才形成候选。若做均值预测，可写成“预测终点距离 + 终点残差下分位 ≥0”；两者都是同一个概率准入思想。分位、概率与置信界必须通过时间外和日期外校准，不从正态模型直接得到已认证的真实概率。

波动只使用过去源/接收时间合格的变化；剩余时间可先分120–60、60–30、30–15、15–0秒四档做低复杂度标定。日期效应样本不足时收缩到全样本/普通日，不叠乘周末、假日和到期倍率。因多次试参，最终未触碰日期须单独留出；同一盘口的多帧不能作为独立观测。旧日历knownAt缺失、官方结算observedAt晚补的限制也应保留：离线时序泛化不等于历史模型当时确实拥有所需信息。

现有`base * sqrt(remaining/120)`并非滚动60秒TWAP终点误差的理论结论。举例，在理想连续同源spot随机游走模型下，剩余时间τ≤60秒时，仅未来未知部分的TWAP标准差随τ^(3/2)而非sqrt(τ)变化；τ≥60秒时方差是σ²(τ−40)。这只是数学反例：当前另一个spot流未必就是官方TWAP的完整底层流，不能把其积分当官方结果。实际应直接校准终点残差，而非以该理想公式部署新数值。

## 日期分类应保留的区别

| 日期或窗口 | 适当处理 |
|---|---|
| 普通日的美股开/收市与夜盘 | 按America/New_York和夏令时划分；香港三时段仍可作统计分组，不能代替美股时钟 |
| 周末 | 用实际波动/深度和终点尾部数据调节，不能直接把旧35/30/40当正式门槛 |
| NYSE整日休市、提前收市 | 与联邦假日分开；缺独立事件样本不生成特殊美元数值，不据此放大仓位 |
| 仅联邦/银行假日但美股开市 | 独立类别；例如10月12日不是NYSE休市 |
| CPI、PPI、就业、GDP/PCE、FOMC声明/发布会/纪要 | 用具体官方时点与不同事件类型；旧前30/后60分钟只是研究窗口，不是官方禁入规则 |
| 股票/股指期权到期 | 不同AM/PM/每日期权分开；仅日期资料不伪造统一精确时点 |
| CME与Deribit加密到期 | CME一般16:00 London，Deribit日/周/月/季以08:00 UTC规则；不能统一为一个纽约时点或由CME推导其他平台 |
| 突发新闻、断流、未识别日程 | 无完整前瞻证据时保留未知，实时波动可反映冲击但不能事后发明事件标签 |

## 动态仓位的可验证规则

逐档含费每份成本为 `c=(买入名义金额+买费)/实际份额`。官方现行Crypto费率表为0.07、每份费用`0.07*p*(1−p)`；市场仍须读取实际元数据和逐档舍入。80–85美分买入的盈亏平衡胜率约81.12%–85.89%，而不是80%–85%。[Polymarket费用](https://docs.polymarket.com/trading/fees)

将经过独立日期校准的胜率一侧置信下界记为`p_L`。可预注册一个保守分数Kelly候选：

`w_raw = lambda * max(0,(p_L−c)/(1−c))`

`w_raw<2.5%`或无合格`p_L`时不形成入场，不能硬抬到最低；否则`w=min(10%,w_raw)`。再核对可用现金、请求最低份数、单次及单盘口100份、单盘口正成交一次等原限制。10%是最大许可，不是达到美元偏离倍数就自动使用的档位。lambda是预先选择的风险偏好，不是“历史最优”，也不保证收益。

仅作算术说明：假设含费成本84美分且lambda=0.25，p_L=85%时仅1.5625%（低于最低应不入），86%→3.125%，88%→6.25%，90%→9.375%，92%→截于10%。这不是现有数据已经支持的真实概率或可部署仓位表。

如果目标先要求`p_L>=95%`，大部分84美分交易的四分之一Kelly都会直接到10%上限，说明风险目标和lambda必须一起预注册，不能同时声称“5%反向保证”又随意设计2.5/5/10强度档位。也可先用十分之一Kelly作更保守候选，择优必须在后续未触碰日期检验。

即使理想真正独立样本全部没有反向，单侧95%反向率上界仍为`1−0.05^(1/n)`：30次为9.50%、38次7.58%、59次4.95%。真实五分钟交易同日相关会使有效支持更少，因此不能用几十次同日零反向认证<5%风险。现有数据没有支持按该公式自动上调10%的校准证据。

更大的仓位还可能显著降低完全成交率：84美分含费成本附近，100份约需84美元；约926美元账户的10%预算约92.6美元，会超过100份的请求上限，原规则应拒绝整笔比例请求，不能自动缩成较小比例。定仓必须同时预测深度与份额合法性，否则“更强就加码”恰会减少可执行机会。

官方FAK只表示立即吃可得部分并取消余量，接受/延迟响应不等于真实成交。`amount`是费前本金，`maxSpend`是含费总支出上限；应保留两者及执行费用，不以报价触碰当成交。[Polymarket下单规则](https://docs.polymarket.com/trading/place-orders)
