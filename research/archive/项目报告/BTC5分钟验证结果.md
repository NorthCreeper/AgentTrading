# BTC 5 分钟工作流：本阶段验收结果

已完成一个可以直接运行的模拟订单闭环，并用真实公开行情验证了轮次切换及离线回放一致性。验收整理日期：2026-09-08。

## 实现范围

当前 BTC 5 分钟盘口发现 → Up/Down token 核对 → 读取费用、价格步长和最小订单量 → 盘口与 Chainlink 60 秒 TWAP 记录 → 本地模拟挂单 → 等待超时 → 撤单并核对累计成交 → 按剩余数量限价吃单 → 模拟卖出与对账。

提交成功不会直接增加持仓；卖单挂出不会直接清仓。撤单失败、订单结果不明、行情过期和轮次变化会阻止不安全的替换操作。未成交库存会继续显示。

## 直接运行

在 `归档用户目录\Documents\Trade` 打开 PowerShell：

```powershell
# 离线演示，不联网
.\启动BTC5分钟验证.ps1 -Mode demo

# 运行测试
.\启动BTC5分钟验证.ps1 -Mode test

# 连续六分钟只读观察真实行情
.\启动BTC5分钟验证.ps1 -Mode observe -Seconds 360

# 用真实行情驱动本地模拟，不会下真实订单
.\启动BTC5分钟验证.ps1 -Mode paper -Seconds 360
```

脚本会显示结果目录。无需配置钱包或私钥，无需安装整个 CloddsBot 的依赖。每次运行是独立的模拟会话。

## 当前边界与后续

本阶段新增了独立的 `btc5m-lab` 验证入口及仓库启动命令。原 CloddsBot `crypto-hft` 实盘模块尚未替换，不能据此认为原实盘代码已经修复。没有执行真实交易，也没有运行完整 CloddsBot 的构建或全部测试。

后续实盘接入需要官方 SDK 交易适配器、实际成交/净份额对账、重启恢复、最终结算与赎回，并配置用户确认的资金和风险限额。当前六分钟观察验证了跨轮行为，不等于长时间稳定性测试；当前模拟也不包含真实排队、网络执行延迟和交易所最终费用舍入。
