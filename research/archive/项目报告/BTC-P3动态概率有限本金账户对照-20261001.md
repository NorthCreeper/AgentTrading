| 项目 | 固定规则 |
| --- | --- |
| 概率来源 | 原始 Up 中间价、原固定模型、原在线校准模型；Down 使用各自的互补概率 |
| 本金 | 每模型独立 $10 / $100；研究本金不计入主账户 |
| 决策时点 | 盘口第120–125秒内的原自然预测，只接收实例激活后且当时新鲜的来源 |
| 金额 | 每笔请求 $1 名义买入金额，模拟费用另计；从原始深度重新报价，不沿用用户改过的研究报价金额 |
| 方向 | 两方向足额原报价中，选择扣费预计兑付利润最高且大于零者；相同值按固定顺序选择，否则跳过 |
| 仓位 | 每账户同时最多一笔；每盘口最多一次意图，无同轮追单或历史补单 |
| 执行 | 等待1秒后，使用其后3秒窗口内第一份合法且源时间更新的报价；保留原方向、概率与2¢保护价 |
| 执行复核 | 本地预演保护价内 FAK；按实际可得份额、名义金额与费用复核现金和正预计价值。零可成交、预算不足、价值消失或窗口过期单列 |
| 部分成交 | 只扣实际成本和费用，保留真实所得份额，未成交部分不算仓位 |
| 退出 | 本研究持有至完整身份核实后的模拟结算，现金在实际处理时释放；不在5分钟结束时提前使用未来结果 |
| 暂停 | 暂停/停止开仓立即终止尚未执行的研究意图；已有仓位继续核实结算，恢复后同轮不追单 |

预计价值计算为 `实际可得份额 × 保存的对应方向概率 − 实际名义成本 − 模拟手续费`。这个数值只是依据模型的判断，不能保证其概率正确或未来赚钱。

原始报价及执行帧同时要求 `源时间 ≤ 接收时间 ≤ 帧时间 ≤ 当前时间`，并通过新鲜度、价格层级和完整盘口身份检查。交叉审阅发现的未来帧缓存边界已修复，无效帧不会后来变成可用净值依据。结算校验盘口、condition、双 token、开始/结束时间、开盘价及互补兑付；开盘数值容差为1e−7，证据不合格保留未知，不强行结清。

持仓净值在尚未到期且有合法报价时，采用2¢保护范围内**足额可卖深度的扣费价值**。范围内无法足额卖出或到期尚未核实，则显示现金至现金加份额的兑付范围。没有把未核实仓位按零计算，也没有用未知净值给出确定ROI。

本次研究的 $1、120秒观察锚和持有至结算，是比较三个概率源所需的统一实验条件。主 One-Tap 金额仍可修改，主退出仍为 `market-information-v1`。手动 One-Tap 买入继续自动管理；未恢复 $0.50/$2 固定阈值、60秒持有上限或最后一分钟强退。

官方市价订单文档区分买入金额、卖出份额及最坏成交价；本研究据此保留金额执行和价格保护，并使用现有模拟费用模型。它尚未模拟真实竞争、网络排队、结算链上成本或所有实盘收费/精度细节，不应直接视为真实 One-Tap 成交的复刻。[Polymarket 订单说明](https://github.com/Polymarket/agent-skills/blob/main/order-patterns.md)、[官方费用说明](https://docs.polymarket.com/trading/fees)。
