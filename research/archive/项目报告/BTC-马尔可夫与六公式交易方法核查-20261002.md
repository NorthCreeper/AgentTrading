# BTC 5分钟马尔可夫与六公式交易方法核查

日期：2026-10-02，香港时间。性质：候选研究分析，不是回放通过或策略部署。当前有效方案仍为v1.6，原策略、资金账户、候选登记及冻结历史报告不变。

## 判断

可以保留“按市场状态估计正确结算事件的概率，用可执行价格和费用寻找价值差，核实结果后受控更新”的结构。不能从“87%”“每81秒一笔”或六个公式一致推出已存在盈利优势。材料没有交易员地址、源码、原始全部成交/资金流、样本外校准及扣费记录，无法核实所述实绩。

一天288个5分钟周期只是全天连续开市的理论数量。每81秒一笔若全天如此，约1067笔下单；若“笔”包含买、卖、取消后重试或不同合约，不能解读为1067个独立盈利机会，更不是目标频次。

## 马尔可夫：可做候选，先纠正预测目标

下一根交易所K线延续当前趋势，与“当前具体盘口按官方规则结算为所买方向”是不同事件。现有工作流源码`dashboard/settlement.mjs`指向Chainlink BTC/USD 60s TWAP；核对的[官方5分钟盘口规则](https://polymarket.com/event/btc-updown-5m-1789894800?outcomeIndex=0)也引用该数据流，并与盘口起始参考比较。后续模型必须逐市场核对规则，不能假定所有历史盘口或15分钟盘口同一口径。

例如BTC仍低于当前轮基准，即使下一小段K线上涨，也不保证到期TWAP越过基准。剩余时间、当前基准偏离、近期波动、趋势持续时长、参考数据收到时刻都应进入正确事件的模型；新鲜度或历史窗口不足时保持缺测。

马尔可夫转移概率可用少量趋势/波动状态、平滑估计和收缩，防止稀疏状态产生接近100%的估计。是否需要隐状态模型，应由新日期增量决定，复杂模型不是预设优势。需要报告每状态的独立盘口数、跨日覆盖、校准、参数不确定性和费用后表现；同轮的数百帧不能当数百个独立胜负样本。

87%只是估计值，没有样本量、标签定义和样本外验证就没有可信度保证。并且胜率不是收益阈值：即使真实胜率87%，支付90¢买一份到期赢得$1，费前期望也是−3¢；较低胜率的便宜合约反而可能更有价值。

## 六公式逐项筛选

| 方法 | 正确用途 | 当前取舍 |
|---|---|---|
| LMSR | 自动做市报价机制，库存及流动性参数决定报价；不自动生成BTC真实概率 | 不采用为Polymarket公允价或必然回归依据 |
| Kelly | 在已知赔率和可信优势下分配风险，追求长期对数财富增长 | 概率/净优势未通过前继续固定$1；不凭故事增加仓位 |
| EV | 正确事件概率与实际成交、费用、退出方式之间的经济比较 | 最高优先级；加入模型误差与执行成本，再验证完整账户 |
| KL | 衡量分布差异，不提供谁正确、交易方向或回归时间 | 先做同事件偏差诊断；5m/15m不能直接当套利信号 |
| Bayes | 有先验和有效似然时更新概率、缓解稀疏估计 | 可保留；避免重复计入相关信息，只用当时已得数据 |
| Avellaneda–Stoikov | 限价簿做市的库存风险及报价优化 | 保留库存/成本/不追价思想；原公式不直接用于0/1到期合约 |

Polymarket当前通过CLOB匹配用户报价，实际买入成本由ask及深度决定；它没有LMSR库存曲线保证20¢回归31¢。“31¢公允值”必须来自可信事件模型，才能讨论价值偏离。[官方交易机制](https://docs.polymarket.com/trading/overview)、[Hanson原始LMSR论文](https://mason.gmu.edu/~rhanson/mktscore.pdf)。

凯利在忽略费用、单一二元投注且资本可复用的理想条件下，买价a、赢的概率p、投入资本比例为f*=(p−a)/(1−a)。它的正负与EV同源，不构成第二条独立预测。估计错误、相关仓位、到期资金等待和执行限制都需要额外处理；凯利不保证没有巨大回撤。[Kelly原始论文](https://onlinelibrary.wiley.com/doi/abs/10.1002/j.1538-7305.1956.tb03809.x)。

5m和15m通常有不同起点、基准、剩余时间或结算统计量。BTC先涨后跌可使5m Up与15m Down同时成立；两个上涨事件概率不必相等。只有逐项核对后具有共同结算统计量/时点及已知阈值包含关系，才可讨论逻辑概率界限，且仍须计算所有状态下的组合支付与成交成本。KL大本身不是回归或无风险套利证据。

贝叶斯更新要求“给定真实结算方向时，信号出现的似然”可估计；成交量放大、价格移动和订单簿可能是同一现象，不能当独立证据重复强化。新BTC区块出现本身不构成短时涨跌优势。当前历史未记录的特征不能事后补造。

Avellaneda–Stoikov原模型研究做市报价、订单到达和库存风险，保留价是库存调整后的报价中心，不是BTC预测胜率。二元合约0/1边界及到期支付、参考价和成交选择风险需要重新建模；maker不收交易费并不证明能成交或获利，触价、挂单和返佣宣传不视为自身成交。[原始论文](https://math.nyu.edu/inmemoriam/avellaneda/HighFrequencyTrading.pdf)、[Polymarket费用](https://docs.polymarket.com/trading/fees)。

## 建议保留的决策结构

正确事件与因果数据 → 一个可校准的条件概率估计 → 深度/延迟/费用后的预期价值 → 有限资金执行 → 核实结果和版本化评审。

持有至结算时，Q份的净EV为：Q×(p−实际平均买价)−买入费−未包含于成交价的其他成本。保守评估可用经过校准且考虑估计误差的概率下界p_L，不能把模型点估计当确定真值。费用读取目标市场当时的实际参数，不能将今天的费率反向覆盖全部历史。[官方费用与参数入口](https://docs.polymarket.com/trading/fees)。

提前卖出的策略需要预测未来实际净卖出收入，不能直接用结算概率代替。已有仓位可比较“继续持有的预期剩余支付/转售价值−占用成本”与“当前可执行净卖出金额”；原买入成本在这两项相对比较中是共同沉没成本，仍完整保留财务损益。模型不适用或未知时不能伪造退出判断。

Bayes/马尔可夫生成p，EV根据p和报价算优势，Kelly用同一p和赔率算风险；三者不独立。KL提供诊断，LMSR是机制，A-S是报价控制。把六者作为六票AND门，会改变选择样本，可能减少机会，但不自动提高准确率或净收益。

午夜可以自动做财务/来源/校准与状态诊断。阈值更新则须预先固定数据窗口、标签延迟、更新幅度及采用规则，并将整套“今日信息→次日参数”政策做因果前向回放。每天从当天已交易样本挑最赚钱阈值会遗漏未入场机会，也可能追逐噪声；波动增加不意味着概率门槛必须单调从87%升至91%。[White的数据窥探研究](https://onlinelibrary.wiley.com/doi/10.1111/1468-0262.00152)。

## 与现有证据的关系和研究顺序

上一轮冻结的5070盘口/23观测日期/114账户中，18变体没有历史采用资格。基准已完成费前+$13.7037，费用$112.9820，净−$99.2783；固定校准胜率66.97%却仍亏；在线校准未显示稳定增量。这支持优先寻找真实可执行的信息优势，不支持先增加频次或启用凯利扩大金额。[完整已完成研究](BTC-P4%E8%87%B3P6%E5%85%A8%E5%8E%86%E5%8F%B2%E9%AA%8C%E8%AF%81%E4%B8%8E%E5%80%99%E9%80%89%E8%BF%90%E8%A1%8C-20261002.md)。

1. 先冻结少量候选：市场概率基准、事件对齐的BTC状态模型、加入马尔可夫持续状态后的模型，分别测试状态特征是否有独立增量。
2. 在共同机会集合中记录预测、状态样本量/不确定性、买卖深度、费用、剩余时间及官方标签知晓时刻，包括未入场机会；按覆盖筛选，不能称所有5070轮都有完整外部BTC/15m数据。
3. 按日期顺序训练/检验，标签只能在真实收到后进入学习。同轮/同盘口相关样本按轮和日期处理；23日期也不保证充分覆盖市场状态。
4. 先比较概率校准，再按固定$1、真实延迟/部分成交/库存/结算等待复算完整账户的净收益、压力、回撤和占用；概率评分改善并非收益改善。
5. 依现有v1.6流程，新增规则先完整历史筛选，再用新的未来日期确认。已经查看过的旧测试集只能辅助探索；不反复优化87/89/91并把最佳历史结果当未见验证。失败候选保留，采用资格不以减少亏损或提高胜率替代。

本文未创建新的交易候选实例，未更改任何开平仓、金额、自动更新参数或运行控制；方法参考与已验证实现严格区分。
