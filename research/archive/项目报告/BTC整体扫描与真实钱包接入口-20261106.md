# BTC 工作流整体扫描与真实钱包接入口

核验时间：2026-11-06 09:10:42 HKT。本次已部署完成；后台自动模拟运行、未暂停、无异常锁，真实交易关闭。控制台：我的钱包（历史本地服务）。

## 使用方式

1. 打开控制台，点击顶部“接入钱包”，或左侧“我的钱包”中的“接入我的钱包”。
2. 从 Polymarket 个人菜单复制账户钱包地址，填入窗口后点击“连接并查看余额”。有浏览器钱包扩展时，也可展开可选项读取签名钱包的公开地址，再确认实际账户钱包地址。官方区分 Deposit / Proxy / Safe 账户钱包与签名地址，两者可能不同，不能把签名钱包余额直接当成交易账户余额。[官方账户说明](https://docs.polymarket.com/trading/wallets-auth)
3. 需要自动恢复只读查询时，自行勾选“在此浏览器记住公开账户地址”。默认不勾选；只保存经过格式校验的公开账户地址，不保存签名地址、会话令牌或凭证。关闭浏览器存储时会提示无法保存。
4. 卡片显示地址、现金余额、更新时间、区块及错误状态。可以刷新、更换地址或“断开本控制台”；断开清除该浏览器记住的地址并停止此连接查询。

当前接口只读取 Polygon 上指定账户的 pUSD 现金，不含持仓净值和真实成交账本；合约地址与6位精度已按官方资料核对。连接不会启用真实自动交易。[官方合约](https://docs.polymarket.com/resources/contracts)、[pUSD 说明](https://docs.polymarket.com/concepts/pusd)

用户尚未提供或选择钱包，因此当前保持“尚未接入”。没有对用户钱包发起签名、代币授权、入金、买卖或转账；钱包交互与模拟账户资金、收益统计分开。两个固定链上查询服务的网络、区块及代币精度探测均成功，但未查询任何用户账户余额。

## 本次修复

- 钱包入口由账户切换内隐藏项提升为独立模块，同时保留原账户视图。
- 修复异步或迟到的钱包扩展公告被漏掉；按EIP-6963保留页面生命周期监听并去重。[扩展发现规范](https://eips.ethereum.org/EIPS/eip-6963#announce-and-request-events)
- 切换地址或断开取消旧链上查询；即使底层忽略取消，旧请求也不能继续后续阶段/备用查询或覆盖新余额。
- 余额读取有8秒响应限制；钱包控制请求有12秒限制并覆盖响应正文等待，超时后释放页面控制。其他交易命令行为保持。
- 后台重启或页面离开后丢弃旧钱包操作结果；旧操作的结束处理不能解除新操作的忙状态。断开意图抑制自动恢复。
- 浏览器从历史缓存返回时恢复单一刷新定时器及已有钱包事件监听，不再次请求公开账户授权；自动恢复失败只在后续成功余额读取后再试，避免高频页面更新反复请求。
- 明确区分未知余额、真实零余额、过期观测和大额精确余额；浏览器无法记住地址时正确提示。
- 校正记住选项的复选框尺寸与对齐，并实测窗口打开和关闭。

钱包专项28项、完整回归974项全部通过；新增测试共16项。最初全套测试有一次随机测试端口被Node fetch禁止，导致1项HTTP测试失败，未关联生产18790端口；未改生产行为，完整重跑及最终变更后974项均通过。原失败日志保留为测试环境证据。
