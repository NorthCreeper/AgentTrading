# 数据与复算示例

[paper-summary.csv](paper-summary.csv) 是已归档模拟账本的汇总。日期采用香港时间，费用和净额以美元保留两位小数。盈利笔数空白表示该字段未在摘要披露。`parent_cohort` 表示该行所含的交易也属于哪一组，汇总时按范围分别读取。 [模拟运行报告](../PAPER-RUN-REPORT.md)

[synthetic-rounds.csv](synthetic-rounds.csv) 的 12 行均为手工构造。每行代表一轮中的一次教学观察，使用虚构标识、报价、成交和结算结果。金额以整数美分计算。合成例固定给出成交份额及示例费用，生产程序的盘口深度、执行延迟、动态风险保护、真实费用计算和逐轮去重另有实现。

| 字段 | 含义 |
| --- | --- |
| `case_id` | 合成案例编号 |
| `seconds_left` | 距这一轮结束的秒数 |
| `feed_status` | 行情及时 `fresh`、过期 `stale` 或缺失 `missing` |
| `twap_delta_usd`、`threshold_usd` | 参考价相对开盘的偏离和本轮门槛，单位为美元 |
| `up_ask_cents`、`down_ask_cents` | Up、Down 的最低卖出报价，单位为美分 |
| `filled_shares`、`fee_cents` | 给定的模拟成交份额和费用。份额 0 表示已准备下单但未成交，空白表示该行没有进入执行。 |
| `winner` | 已给定的合成结算方向。成交后留空表示等待结算。 |

复算时先检查行情是否及时且齐全，再检查是否进入最后 120 秒、偏离绝对值是否达到门槛。偏离为正选择 Up，为负选择 Down。所选方向报价须在 80–85 美分，对侧报价须不高于 20 美分。通过后读取给定成交。买入成本为报价乘份额加费用，方向匹配的已结算合约按每份 100 美分兑付。等待结算时单列已支出成本，净额留空。

在仓库根目录运行 [复算脚本](../replay-synthetic.py)。

```text
python research/replay-synthetic.py
```

预期结果为 12 轮中 4 轮规则拒绝、2 轮观测不足、6 轮满足入场条件。满足条件的轮次中，1 轮未成交、1 轮成交后待结算、4 轮已结算。已结算中有 3 轮盈利，含费支出 34 美元、兑付 30 美元、净亏 4 美元。待结算占用的 8.50 美元单独列示。
