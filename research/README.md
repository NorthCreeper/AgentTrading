# BTC5M 研究资料

这里整理项目在比特币 5 分钟涨跌市场上的研究方法、两代自动模拟策略，以及可以离线复算的示例。读者可以先看结果，再沿着方法和代码核对统计口径。

| 内容 | 阅读入口 |
| --- | --- |
| 两代策略如何演进、哪些候选停留在研究阶段 | [策略沿革](STRATEGY-HISTORY.md) |
| 如何核对行情时点、成交、费用和结算 | [研究方法](METHODOLOGY.md) |
| 早期盘口动量和 Ray 策略的模拟运行结果 | [模拟运行报告](PAPER-RUN-REPORT.md) |
| 汇总 CSV、合成样本和字段说明 | [数据与复算示例](data/README.md) |
| 按原目录浏览历史报告、专题文档和图表 | [研究与分析档案](archive/README.md) |

历史汇总来自项目保存的自动模拟账本和对应的冻结报告。原始逐笔行情、账户记录及完整报告档案由项目维护者保管。示例数据为手工构造，可用来复算判断与记账过程。[项目数据来源](../docs/DATA-SOURCES.md)

在仓库根目录运行以下命令即可复算示例。脚本使用 Python 3.10 或更高版本的标准库，离线读取 CSV。

```text
python research/replay-synthetic.py
```
